# 夸克网盘分享 · 免登录下载器

粘贴夸克分享链接即可解析并下载，全程不需要登录夸克账号。解析与下载由本服务直连夸克官方公开接口，不经过任何第三方解析服务。

- 零第三方依赖：仅使用 Node.js 内置模块（Node.js 18+，实测 22 可用）
- 单文件独立版：体积约 34 KB，内嵌网页界面，无需 `npm install`
- 多会话隔离：多人/多标签页同时使用互不干扰

## 为什么不能做成纯静态网页

夸克接口会校验请求来源（`Origin`），只接受夸克自家站点或**不带 Origin 的服务端请求**；浏览器里的纯静态网页（包括 GitHub Pages）无论放在哪里都会返回 403，且响应不带任何 `Access-Control-Allow-*` 头。

**所以必须有服务端中转一层**。本仓库的 `quark-dl.js` 就是这一层：既是网页服务，也是代理下载服务。因此“在线调用”需要部署在能运行 Node.js 的平台上，GitHub 仓库本身只承担代码托管。

## 本地使用

前置：安装 [Node.js](https://nodejs.org) 18 或更高版本（命令行执行 `node -v` 可看到版本号）。

```bash
node quark-dl.js
```

浏览器会自动打开 http://127.0.0.1:8787 ，粘贴夸克分享链接即可解析下载。

Windows 用户也可直接双击 `启动.bat`（同目录，自动检测 node 并启动）。

停止服务：关闭命令行窗口，或按 `Ctrl+C`。

## 在线部署（实时调用）

服务默认监听 `127.0.0.1:8787`；托管平台注入 `PORT` 环境变量时会自动改绑 `0.0.0.0:PORT`。任意支持 Node.js 的托管平台均可直接部署：

| 平台 | 启动命令 | 说明 |
|---|---|---|
| Render / Railway / Koyeb | `node quark-dl.js` | 平台注入 `PORT` 后自动对外监听 |
| Docker | 见 `Dockerfile` | `docker build -t quark-dl . && docker run -p 8787:8787 quark-dl` |
| 字节 CloudStudio / 云环境 | `node quark-dl.js` | 网关会把应用映射为公网域名 |

部署后访问 `<你的域名>/` 即可使用。

## 访问口令（部署到公网强烈建议开启）

任何人拿到网址都能消耗你的流量，公网部署务必设置口令。

设置方式（优先级）：环境变量 `ACCESS_TOKEN` > `local.config.json`（部署环境自动读取）。

- 环境变量方式：部署平台控制台设置 `ACCESS_TOKEN=你的口令`
- 配置文件方式：在 `quark-dl.js` 同目录创建 `local.config.json`：
  ```json
  { "accessToken": "你的口令" }
  ```
  （已加入 `.gitignore`，不会提交到仓库）

开启后访问需在网址后加 `?k=你的口令`，例如 `https://你的域名/?k=你的口令`；输入一次后浏览器会记住 30 天。

## 能力范围与限制

| 类型 | 大小 | 通道 |
|---|---|---|
| PDF | 任意大小 | 预览通道，拿到原始文件（服务端返回哈希可校验） |
| 图片 / 文档 / 压缩包等普通文件 | 单个 ≤ 约 50 MB | 免登录直链通道（服务端返回 23018 即超限） |
| 大体积视频 / 大压缩包 | 超过上限 | 原文件下载会被服务端拒绝，本工具不提供有损预览流 |

- 直链有效期约 3–6 小时，工具每次下载都会重新取链
- 解析会话保留 30 分钟，过期后重新点「解析」即可
- 端口被占用：设置环境变量 `PORT` 换一个端口

## 接口一览

| 路径 | 说明 |
|---|---|
| `GET /` | 网页界面 |
| `GET /api/parse?url=<分享链接>&pwd=<提取码>` | 解析分享，返回全部文件与解析会话 sid |
| `GET /api/link?sid=...&pwdId=...&stoken=...&fid=...&token=...` | 获取单个文件的下载直链 |
| `GET /dl?sid=...&...` | 代理下载文件（支持 Range 断点续传） |
| `GET /api/health` | 健康检查 |

> 本工具仅用于解析公开分享链接的个人下载场景，请遵守夸克网盘服务条款与相关法律法规，勿用于侵权传播。
